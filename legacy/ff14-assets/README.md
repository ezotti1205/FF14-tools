# FF14 総資産ログ

ゲームを終了する時点の**総資産額を1日1回だけ記録**していく、家計簿のような単一ページのWebアプリです。
アイテム単位の取引は扱いません。ビルド不要で、`index.html` をブラウザで開くだけで動きます。

- ゲームクライアントには一切アクセスしません（メモリ読み取り・パケット解析・画面認識・自動操作なし）。入力はすべて手入力です。
- データはブラウザの localStorage に保存されます。JSONのエクスポート/インポートに対応しています。
- 既存の `ff14-ledger`（収支記録アプリ）とは **localStorage のキーが完全に別** です。互いに干渉せず、並行して使えます。

## ファイル構成

```
index.html        画面
css/style.css     スタイル（ダークテーマ）
js/util.js        日付・数値のユーティリティ
js/store.js       localStorage への永続化、エクスポート/インポート
js/agg.js         期間の切り出し・粒度の自動選択・増減の集計
js/chart.js       グラフ描画（Chart.js のラッパ）
js/app.js         画面制御
vendor/           （任意）Chart.js をオフラインで使う場合の置き場
```

ES Modules ではなく通常の `<script>` で分割しているため、ローカルファイルを直接開いてもCORSで止まりません。

## グラフライブラリ

Chart.js 4.4.1 を使います。読み込みは次の順に試します。

1. `vendor/chart.umd.js`（ローカル）
2. `https://cdn.jsdelivr.net/npm/chart.js@4.4.1/dist/chart.umd.js`
3. `https://unpkg.com/chart.js@4.4.1/dist/chart.umd.js`

**オフラインでも使いたい場合**は、上記2のURLのファイルを保存して `vendor/chart.umd.js` として置いてください。以降はネット接続なしで動きます。
どれも読み込めなかった場合はグラフ部分に案内が出ますが、**増減などの数値はライブラリなしでも表示されます**。

## 使い方

### 記録

画面上部に固定されたフォームから入力します。

| 項目 | 内容 |
|---|---|
| 日付 | 既定は今日。「今日」ボタンで戻せます |
| 総資産額（ギル） | 必須 |
| メモ | 任意（例: 「零式ドロップ売却」「古戦場終わり」） |

金額はカンマ付きや短縮表記でも入力できます。

```
12345678   1.2億   3500万   12,345,678   12m
```

入力中は「直前の記録からいくら増減するか」がフォーム下に出ます。

### 同じ日に2回目を記録したとき

確認ダイアログが出て、次のどちらかを選べます。

- **上書きする** … その日の記録をすべて消して1件だけにする（入力ミスの修正向け）
- **追記する** … 同じ日の2件目として残す（一覧では「同日2件」と表示）

グラフと集計は、**その日の最後に入力した記録**を使います。あとから追記したものが必ず最後になるので、
「入力ミスに気づいて入れ直す」場合はどちらを選んでも最新の値が反映されます。

一覧の「編集」からは、日付・金額・メモをその場で直せます。

### 電卓（内訳の合計）

総資産額の入力欄の横にある「電卓」ボタンを押すと、手持ち・リテイナー・倉庫などバラバラな金額を
行ごとに入力して合計できるパネルが開きます。

- 行は「＋ 行を追加」で増やせます（ラベルは任意）
- 金額欄は総資産額と同じく `1.2億` `3500万` などの表記に対応
- 「総資産額にコピー」で、合計をそのまま総資産額欄に入れられます
- 入力中の内容はブラウザに自動保存されるので、途中でページを閉じても消えません
  （localStorage キー: `ff14assets.v1.calcdraft`。記録そのものとは別に保存され、エクスポートJSONには含まれません）

### 表示期間と粒度

期間タブを切り替えると、グラフの粒度が自動で変わります。

| タブ | 対象範囲 | 粒度 |
|---|---|---|
| 週 | 直近7日 | 日次 |
| 月 | 直近31日 | 日次 |
| 年 | 直近52週 | 週次（各週の最終記録） |
| 全期間 | 最初の記録〜今日 | 〜120日: 日次 / 〜500日: 週次 / それ以上: 月次 |

総資産は累積値なので、集計は平均ではなく**その期間の最後の記録**を代表値にします。
記録のない日は 0 で埋めず、記録のある点どうしを線でつなぎます。

これにより描画点は最大でも120点程度に収まるため、365件の日次記録があってもタブ切り替えは数ミリ秒で終わります。

### 増減の計算

```
増減   = 期間内で最後の記録 - 基準額
増減率 = 増減 ÷ |基準額| × 100
基準額 = 期間開始より前の直近の記録（無ければ期間内で最初の記録）
```

グラフの上に、期間の増減・増減率のほか、記録日数／期間内の最高・最低／1日あたりの平均増減が出ます。

### データ管理

- **JSONをエクスポート** … `ff14-assets-YYYY-MM-DD.json` としてダウンロード
- **JSONをインポート** … 「置き換える」「追加する（マージ）」を選択。マージでは同じ記録（IDまたは日付・金額・メモが一致）はスキップします
- **サンプル365件を生成** … 動作確認用。現在の記録は置き換えられます
- **すべて削除**

別のブラウザや端末に移すときは、エクスポートしたJSONをインポートしてください。

## データ形式

localStorage のキーは次の2つです。

| キー | 内容 |
|---|---|
| `ff14assets.v1.records` | 記録の配列 |
| `ff14assets.v1.settings` | 選択中の期間タブ、一覧の表示件数 |
| `ff14assets.v1.calcdraft` | 電卓パネルの入力中の内訳（任意・下書き） |

記録1件の形は次のとおりです。

```json
{
  "date": "2026-08-30",
  "amount": 12345678,
  "memo": "零式ドロップ売却",
  "id": "mtfjicm8u3ufbv",
  "createdAt": "2026-08-30T08:20:59.360Z"
}
```

`date` / `amount` / `memo` が本体です。`id` と `createdAt` は、同じ日に複数の記録があるときの
並び順（＝どれがその日の最終記録か）を決めるために内部で使います。

インポート時は `id` / `createdAt` が無くても取り込めます。記録の配列だけのJSON
（`[{"date":..., "amount":...}, ...]`）や、`date` がISO日時形式のものも受け付けます。

## 旧実装（ff14-ledger）との関係

`ff14-ledger` は `ff14ledger.v1.records` / `.settings` / `.templates` を使っています。
本アプリはこれらを**読みも書きも削除もしません**。旧実装の所持金（`settings.gil`）の取り込みも行いません。
必要であれば、旧実装で所持金を確認して手入力してください。
