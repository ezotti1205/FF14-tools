# FF14 採集ノード タイマー

FF14 の時間限定採集ノード（エフェメラル／伝説／未知）の出現をカウントダウン表示する単一ページ Web アプリ。
**ビルド不要・サーバー不要。`index.html` をブラウザにドラッグ＆ドロップ（またはダブルクリック）するだけで動きます。**
ゲームクライアントには一切アクセスしません。

## 使い方

`index.html` をブラウザで開くだけ。`file://` で直接開いて動作します（ES Modules や fetch を使わず、
クラシックスクリプトで組んでいるため）。

初回の通知許可だけは、上部の「ブラウザ通知を有効にする」を押してブラウザのダイアログで許可してください。

## ノードデータ

同梱の `data/nodes.js` には、**「ギャザラータイマー：FF14俺Tools」(https://ffxiv.gt.exdreams.net)**
の公開データ（`js/gt_point.js` / `js/define.js`）を変換した **エフェメラル(刻限)・未知・伝説の 225 ノード**が
入っています（採集時刻・座標・最寄りエーテライトなどのゲーム内事実情報。最終取り込み 2026-08-30）。
最寄りエーテライトは「同一エリア内で座標がいちばん近いエーテライト」を計算したものです。

### 最新化

上部の **「exdreamsから更新」** ボタンで、exdreams.net の最新データを取得して置き換えます
（結果は `localStorage` に保存。`file://` でも動作します）。「同梱に戻す」で `data/nodes.js` に戻ります。

### 手動編集

`data/nodes.js` を書き換えてリロードするだけです。冒頭コメントにスキーマの説明。要点:

- 中身は `window.FF14_NODES = [ ... ];` という素の配列（末尾カンマ可、キーはクォート不要）。
- `spawns`: `[{ startET: 開始ET時, durationET: 継続ET時間 }]`。**ET 時刻で毎エオルゼア日くり返し**。
  未知/伝説は 12 時間おきの 2 窓、刻限は 1 日 1 窓（4 時間）が基本。
- `id` はお気に入り／通知設定のキー。変更するとそのノードの設定がリセットされます。
- `aetheryte` は最寄りエーテライト（街／拠点）名。手動で上書きも可。

> `localStorage` に更新データがある間は、そちらが `data/nodes.js` より優先されます。
> JSON ではなく `.js` なのは、ローカルサーバーなしで `file://` から読み込めるようにするためです。

## 機能

- エオルゼア時間（ET）と現実時刻を常時表示、1 秒ごとに更新
- ノードごとに「出現中 / 次の出現まで残り X 分 Y 秒」を一覧表示
- 出現中を先頭に固定し、色で区別（青＝出現中／赤＝出現中で残り1分未満／黄＝通知分前）
- 採集場所（エリア名・最寄りエーテライト・座標）を大きく表示（移動中にパッと確認できるように）
- 出現 N 分前（既定 5 分、上部で変更可）にブラウザ通知。ノード単位で ON/OFF
- 絞り込み: 採掘/園芸、レベル帯、種別（刻限/未知/伝説）、フリーワード（アイテム名・エリア・地点・関連アイテム・備考）
- お気に入り（★）と「お気に入りのみ表示」トグル
- 設定（お気に入り・通知・絞り込み・通知分）は `localStorage` に保存。閉じて開き直しても復元
- 設定の JSON エクスポート / インポート（上部ボタン）

## ET 計算

`js/eorzea.js` に切り出し。現実 1 秒 = ET 約 20.571 秒 / 1 エオルゼア日 = 現実 70 分。
`unixミリ秒 × (3600 / 175)` を ET ミリ秒として扱う。

単体テストは `tests.html` をブラウザで開くと実行され、結果が画面表示されます（21 件）。

## ファイル構成

```
index.html          画面本体（CSS・ロジック・exdreams変換を内包）
tests.html          eorzea.js のテスト（ブラウザで開く）
js/eorzea.js        ET 計算ユーティリティ
js/eorzea.test.js   テストケース
data/nodes.js       ノードデータ（exdreams由来／手動編集も可）
```
